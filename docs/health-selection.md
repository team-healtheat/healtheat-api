# 건강요인 선택 연동

온보딩과 수정 화면에서 질환을 복수 선택하고 기타를 직접 입력한다. 화면에서 목록 선택, 기타 입력, 없음 선택과 최종 확인을 구현한다. 기존 분석 API는 구버전 호환용이며 새 화면에서는 호출하지 않는다.

`GET /api/health-profiles/options`는 12개 선택 항목 문자열 목록을 반환한다.

`PUT /api/health-profiles/selection`은 인증 쿠키와 CSRF 토큰이 필요하다. 예:

```json
{"conditions":["당뇨병", "통풍"],"other":["기타 입력"],"none":false}
```

없음을 선택했다면 `{"conditions":[],"other":[],"none":true}`를 보낸다. 없음과 항목을 같이 보내거나, 아무것도 선택하지 않은 상태에서 `none:false`를 보내면 400이다. 이름이 정확히 같은 중복은 하나로 저장하고, 다른 표현의 동의어나 하위 질환은 자동 병합하지 않는다. 기타 입력은 그대로 보존한다.

저장은 해당 사용자의 현재 활성 건강요인 전체를 교체한다. 목록에 빠진 기존 항목은 비활성화되며 조회 이력은 남는다. 기존 계정의 항목은 사용자가 저장하기 전까지 유지하고, 수정 화면에서 기존 항목을 미리 보여줘 사용자가 유지 여부를 선택해야 한다. 식단 추천은 활성 항목만 사용한다.

`GET /api/health-profiles/selection`은 `completed`, `none`, `factors`(활성 항목)를 반환한다. 기존 사용자의 `completed`는 선택 방식으로 저장하기 전까지 false이며, 활성 항목은 `factors`에서 확인할 수 있다. `none`은 저장된 선택 결과와 현재 활성 항목으로 판단한다. 채팅에서 변경한 건강요인도 현재 활성 항목에 반영된다.

이 기능은 사용자가 보고한 항목을 저장하며 진단이나 식단의 안전성을 보장하지 않는다.
